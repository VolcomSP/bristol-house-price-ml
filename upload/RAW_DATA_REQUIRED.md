# Police.uk raw files

The 36 large Police.uk source files are intentionally excluded from the submission repository.

To reconstruct the crime feature table from raw data, download Avon and Somerset street-level crime data for every month from January 2022 to December 2024 and place the files here using this pattern:

```text
YYYY-MM-avon-and-somerset-street.csv
```

The preparation script requires the standard Police.uk columns including Crime ID, Month, Longitude, Latitude, LSOA code, LSOA name and Crime type.

Official download page: <https://data.police.uk/data/>
