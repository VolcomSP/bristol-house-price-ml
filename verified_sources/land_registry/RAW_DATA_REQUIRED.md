# HM Land Registry raw files

The national annual Price Paid Data files are intentionally excluded from the submission repository because of their size.

Download and save the files as:

```text
verified_sources/land_registry/pp-2022.csv
verified_sources/land_registry/pp-2023.csv
verified_sources/land_registry/pp-2024.csv
```

Official access page: <https://www.gov.uk/government/statistical-data-sets/price-paid-data-downloads>

Direct file pattern used by the validation code:

```text
https://price-paid-data.publicdata.landregistry.gov.uk/pp-YYYY.csv
```
